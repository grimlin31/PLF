# Política de seguridad

## Versiones compatibles

La rama `main` representa la versión pública vigente del Professional Learning Framework.

## Informar una vulnerabilidad

No abras un issue público si el informe contiene una vulnerabilidad, un secreto o información sensible.

Utiliza el formulario privado de GitHub:

https://github.com/grimlin31/PLF/security/advisories/new

Incluye:

- descripción del problema;
- archivos o versiones afectadas;
- pasos mínimos para reproducirlo;
- impacto estimado;
- posible mitigación, si la conoces.

No incluyas credenciales reales. Si una credencial se publicó accidentalmente, debe revocarse en su proveedor; eliminarla del repositorio no basta.

## Alcance de privacidad

El repositorio público contiene únicamente el Framework genérico. Las instancias reales de Bootcamps, perfiles, registros y estados del estudiante deben permanecer fuera del historial público.
