# Shared Assets

**Version:** 1.0.0  
**Status:** Approved  
**Framework:** Professional Learning Framework

This directory stores assets reusable across multiple Bootcamps.

## Structure

```text
Assets/
├── Diagrams/
├── Images/
└── References/
```

## Rules

- Store only assets that are generic and reusable.
- Profession-specific assets belong inside the corresponding Bootcamp.
- Use stable descriptive filenames.
- Prefer editable source formats when available.
- Reference assets using repository-relative paths.
- Record attribution and licensing when required.
- Do not store secrets, credentials or private personal data.
