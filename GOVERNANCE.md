# Gobierno del repositorio

## Propietario y mantenedor

El propietario y mantenedor final del proyecto es `@grimlin31`.

## Modelo de cambio

- `main` es la rama pública estable.
- Los cambios se proponen mediante pull requests.
- Toda ruta está cubierta por `CODEOWNERS`.
- Todo pull request requiere la aprobación explícita del propietario.
- Las conversaciones deben resolverse antes de fusionar.
- Los controles automáticos deben finalizar correctamente.
- No se permiten force-push ni eliminación de `main`.

## Colaboradores

La participación pública no concede permisos directos de escritura. Las propuestas externas se realizan mediante forks y pull requests.

## Excepciones

El propietario puede aplicar una excepción administrativa para recuperar el repositorio o resolver una emergencia. La excepción debe ser deliberada y quedar registrada en el historial.

## Alcance

Este gobierno protege el repositorio público del PLF. Los Bootcamps personales deben mantenerse en repositorios privados o fuera del control de versiones público.
