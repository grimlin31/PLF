# Contribuir al Professional Learning Framework

El repositorio es público para facilitar su consulta y recibir propuestas. La publicación no concede permiso para modificar directamente el proyecto oficial.

## Flujo obligatorio

1. Crea un fork o una rama de trabajo.
2. Realiza un cambio pequeño y claramente justificado.
3. Abre un pull request hacia `main`.
4. Espera la validación automática.
5. Espera la revisión y aprobación explícita de `@grimlin31`.

Ningún colaborador externo debe tener acceso de escritura directo. Toda contribución se considera una propuesta hasta que el propietario la aprueba y fusiona.

## Alcance público

Se aceptan cambios relacionados con:

- reglas genéricas del PLF;
- documentación pública;
- plantillas reutilizables;
- correcciones verificables;
- mejoras metodológicas compatibles con el alcance aprobado.

No se deben publicar:

- Bootcamps personales o sus estados;
- perfiles de aprendizaje reales;
- nombres, fechas críticas o información profesional privada;
- credenciales, secretos o datos corporativos;
- material de terceros sin permiso.

## Decisión final

`@grimlin31` conserva la decisión final sobre aceptar, solicitar cambios o rechazar cualquier propuesta.
